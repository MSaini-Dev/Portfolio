## ✨ Features

- 🎨 **Modern UI** built with React + Vite + TailwindCSS  
- ⚡ **Fast performance** with Vite bundling  
- 📱 Fully **responsive design** for all devices  
- 🧑‍💻 **Project showcase** with live links & descriptions  
- 📄 **Resume/Contact section** for easy reach  
- 🚀 Deployed seamlessly on **Vercel**
