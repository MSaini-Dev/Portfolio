## ✨ Features

- 🎨 **Modern, Minimal Design** – Clean UI with responsive layout for all devices.  
- ⚡ **Dynamic Animations** – Leveraging Framer Motion for smooth transitions and interactions.  
- 💼 **Projects Showcase** – Highlighting my works like BookFair, ClipCrate, and ChatAI.  
- 📑 **Downloadable CV** – Direct PDF download via Google Drive.  
- 🚀 **Fast & Reliable** – Hosted on Vercel with continuous deployment.  

---

## 🛠 Tech Stack

- **Framework**: React + TypeScript (Vite)  
- **Styling**: Tailwind CSS + Framer Motion  
- **Routing & SEO**: react-helmet-async for dynamic `<head>` meta tags  
- **Deployment**: Vercel  
- **Version Control**: Git & GitHub
