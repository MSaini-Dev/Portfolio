## 📌 Overview  

Welcome to my **developer portfolio**, built with **React, Vite, and TypeScript**.  
This website showcases my projects, skills, resume, and ways to connect with me.  

🔗 **Live Website:** [portfolio-mohit-saini.vercel.app](https://portfolio-mohit-saini.vercel.app/)  
📦 **Repository:** [MSaini-Dev/Portfolio](https://github.com/MSaini-Dev/Portfolio)  

---

## ✨ Features  

- 🎨 **Modern UI** with smooth animations  
- ⚡ **Optimized performance** using Vite  
- 📱 **Fully responsive** for all screen sizes  
- 🧑‍💻 **Projects section** with live links & descriptions  
- 📄 **Resume & contact section** for easy reach  
- 🚀 Hosted on **Vercel** with CI/CD  

---

## 🛠️ Tech Stack  

- **Frontend:** React, Vite, TypeScript, TailwindCSS  
- **Deployment:** Vercel  
- **Version Control:** Git + GitHub
